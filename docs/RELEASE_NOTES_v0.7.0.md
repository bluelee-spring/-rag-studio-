# RAG Studio v0.7.0

本版本把“学员自有属性图”加入数据工作区，并保持本机、独立、可追踪的教学边界。

## 新增

- 图数据页在上传之前展示格式合同、容器 / NODE / EDGE 示例与 JSON / JSONL 下载样例。
- FastAPI 接收 `graph.json`、`graph.jsonl`，异步展示解析、校验、SQLite 入库、节点卡、Embedding、FAISS 与原子发布阶段。
- 严格校验重复 ID、悬空边、schema 类型、关系方向和属性结构；孤立节点与缺少证据形成可见警告。
- 每个图工作区拥有独立 `graph.sqlite3`、schema、校验报告、规范化 JSONL、节点语义卡和 FAISS 文件。
- 自有图查询采用“FAISS 语义锚点 → schema 关系白名单 → SQLite 邻接索引最多 2 跳 → evidence 回收 → LLM”的完整 RAG 链。
- 实验台复用三维语义空间、图模式和逐跳三维子图渲染，并把任意领域节点类型带入画面。
- Windows / macOS 原有一键安装与本地完整模型 / LoRA 加载方式保持不变；自有图不要求 Neo4j。

## 执行边界

- 单图最多 50,000 节点、200,000 边、20,000 证据文档。
- 最多 256 种节点类型、512 种关系类型。
- 单次查询最多 3 个实体锚点、2 跳、100 节点、180 边。
- LLM 不直接持有数据库连接，也不自由生成图查询代码。

## 验证

- 后端测试覆盖 JSON 建库、JSONL 解析、原子失败、异步上传及工作区查询。
- Next.js 类型检查和 Webpack 生产构建覆盖新增代理路由与页面。
